# A* Pathfinding Visualizer

A simple and interactive maze solver built using the **A\*** Pathfinding Algorithm. This project demonstrates how the algorithm finds the shortest path between a start point and an end point while avoiding obstacles.

## Features

- Generate random mazes
- Select custom start and end points
- Visualize shortest path in real time
- Clear and reset grid
- Simple GUI interface

## Controls

- **R** → Generate Random Maze  
- **C** → Clear Grid  
- **SPACE** → Run A* Algorithm

## How It Works

The A* algorithm uses path cost and heuristic distance to efficiently search for the shortest route from source to destination.

## Conclusion

This project helps in understanding graph traversal, shortest path algorithms, and visualization techniques in an interactive way.
